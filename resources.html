Learning Resources

A curated shelf for the intermediate → elite red-teamer journey: the books, channels, feeds, references, blogs, and hands-on labs worth your time. Practice only on systems you are authorized to test.

📚 Books

Field-defining reads. Work through them, don't just shelve them.

  • The Web Application Hacker's HandbookThe web-app bible (pairs with the free PortSwigger Academy).
  • The Hacker Playbook 3 — Peter KimPractical red-team playbook, engagement-flavoured.
  • Penetration Testing — Georgia WeidmanThe classic hands-on intro; still the best first book.
  • The Art of Exploitation — Jon EricksonUnderstand exploitation from the memory up.
  • Practical Malware AnalysisThe reference for static/dynamic analysis fundamentals.
  • Black Hat Python (2e)Tooling and offensive scripting patterns in Python.
  • Bug Bounty Bootcamp — Vickie LiModern web bug hunting, end to end.
  • Red Team Field Manual (RTFM)Terse command reference for the field.
